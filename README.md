# ドリップナビ (drip-navi)

ハンドドリップコーヒーのための、注湯ナビゲーションアプリです。
レシピと杯数を選ぶと豆量・湯量が自動計算され、タイマーが「今どこまで注ぐか」をリアルタイムで案内します。

## ターゲット

趣味でハンドドリップコーヒーを淹れるのが好きな人

## コア価値

1. **自動計算**: レシピと杯数(1〜4杯)を選ぶと、規定量に基づいて豆量(g)と総湯量(ml)が決まる
2. **リアルタイムナビ**: タイマー開始後、「現在の工程」と「あと何mlまで注ぐか」を大きく表示する

## MVPの機能

| # | 機能 | 内容 |
|---|------|------|
| 1 | レシピ選択 | プリセット2〜3種(例: 4:6メソッド、基本の1投ドリップ) |
| 2 | 杯数選択 | 1〜4杯をボタンで選ぶ |
| 3 | 自動計算 | 豆量・総湯量を算出して表示 |
| 4 | 工程の自動展開 | 各工程の注湯量を「総湯量に対する割合」で持ち、杯数に応じて累計mlを再計算 |
| 5 | ナビゲーションタイマー | 現在の工程名、今回の目標累計ml、次の工程までの残り秒数を表示 |
| 6 | 切り替えの合図 | 工程切り替えの数秒前と切り替わり時に音(対応端末ではバイブ)で通知 |
| 7 | 一時停止・リセット | 最低限の操作 |
| 8 | 画面スリープ防止 | ドリップ中に画面が消えないようにする |

### 表示の方針
- 「今回注ぐ量(+60ml)」と「累計の目標(240mlまで)」を**両方**表示する(スケール派・感覚派の両方に対応)
- 蒸らし中は「待ち」と明示し、注湯中の工程と区別する
- 両手がふさがる前提で、大きな文字と少ない操作を優先する

### MVPに含めないもの
自作レシピ、記録・履歴、豆や挽き目のメモ、お気に入り、ログイン、アイスコーヒー対応、湯温管理、スケール連携

## 画面構成

1. **セットアップ画面**: レシピ・杯数の選択 → 計算結果と工程プレビューの確認 → スタート
2. **ナビゲーション画面**: 経過時間、「◯ml まで」(最大表示)、次の工程、一時停止・中止
3. **完了画面**: 使用した豆量・湯量・総抽出時間、「同じ設定でもう一杯」「最初に戻る」

## データ設計(イメージ)

```
レシピ = {
  名前, 1杯あたりの豆(g), 湯の倍率, 挽き目, 湯温,
  工程[] = { 開始秒, 注湯の割合(%), 名前(蒸らし / 注湯1 ...) }
}
```

豆量 = 1杯あたりの豆 × 杯数、総湯量 = 豆量 × 倍率、各工程の累計ml = 割合の累計 × 総湯量。
レシピの追加は、データの追加だけで済む構造にする。

## 技術方針

- **React + TypeScript + Vite**(フロントエンドのみ。バックエンドなし)
- レシピはコード内のデータとして保持する
- 最終的に **PWA** 化を目指す(MVP完成後に `vite-plugin-pwa` を追加)
  - オフライン動作、ホーム画面追加、縦画面固定

### 設計上の注意(PWA化を見据えて)
- **タイマーは `setInterval` のカウントではなく「開始時刻との差」で経過時間を計算する**
  (バックグラウンド復帰時にもズレないため)
- 画面スリープ防止は Screen Wake Lock API を使う(実機での動作確認が必要)
- iOS Safari は `navigator.vibrate` 非対応のため、通知は**音を主、バイブは補助**とする
- 音の再生は自動再生制限があるため、「スタート」ボタンのタップ時に初期化する

## 開発の進め方(予定)

1. プロジェクトの初期構成(Vite + React + TypeScript)
2. セットアップ画面(`useState` と計算ロジック)
3. ナビゲーション画面(`useEffect` とタイマー)
4. 画面遷移と完了画面
5. 音・スリープ防止
6. PWA化
